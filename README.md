# Тибетська — Малі кроки

- `outputs/Тибетська — Малі кроки.html` — актуальний додаток. Відкрий у браузері, щоб навчатися без інтернету.
- `outputs/index.html` — файл для публікації на GitHub Pages. Щоб оновити сайт, заміни ним `index.html` у репозиторії.
- `work/` — файли для редагування й збирання, навчальні дані, перевірки та звіти.
- `Навчальні матеріали/` — копії PDF і Word з iCloud.
- `sites/tibetan-small-steps/` — окрема версія, підготовлена для ChatGPT Sites.
- `Архів/` — рання копія додатка з iCloud.

Особистий прогрес зберігається в браузері. Якщо не бачиш його після відкриття додатка з нової папки, натисни «Відновити з копії» й обери раніше збережений файл. Якщо навчалася на GitHub Pages, можеш завантажити копію прогресу із сайту.

## Вхід на GitHub Pages

У версії `outputs/index.html` є вхід через одноразове посилання на email. Для учасників поза командою Supabase налаштуй власний сервіс надсилання пошти. Адреса повернення після входу — `https://tanyatymo.github.io/tibetan/`.

Якщо в новому проєкті Supabase ще немає таблиці, один раз виконай `work/supabase-progress.sql` у SQL Editor. `work/supabase-config.json` містить адресу й публічний ключ, потрібні сайту; секретний ключ сюди не додавай.

Після змін у додатку з кореня папки виконай `python3 work/build_mini_app.py`, а потім `python3 work/build_github_pages.py`. Завантаж на GitHub новий `outputs/index.html`. Перевірка форми та синхронізації з імітацією сервера: `node work/test-github-account.cjs`.
